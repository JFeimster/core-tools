# Core Tool Directory

A static-first Next.js App Router directory for business finance tools, embeds, landing drafts, brand pages, and curated playbooks.

Live site:

```txt
https://core-tools.vercel.app
```

## What It Does

- Browse and filter finance tools
- Open static tool detail pages
- Run lightweight formula calculators
- Generate landing page draft copy
- Copy iframe embed snippets
- Browse tools by brand
- Build curated collections/playbooks
- Generate tool JSON from the admin Tool Builder
- Generate collection JSON from the admin Collection Builder

## Stack

- Next.js 15.3.8
- React 19
- TypeScript
- TailwindCSS
- Static export
- JSON-driven data
- Vercel deploy
- No database
- No auth
- No server actions

## Builder Workflow

### Add or edit tools

1. Open `/admin/tool-builder`.
2. Generate tool JSON.
3. Paste the object into `data/tools.json`.
4. Validate data through the repo workflow.

### Add or edit collections

1. Open `/admin/collection-builder`.
2. Select and order tools.
3. Generate collection JSON.
4. Paste the object into `data/collections.json`.
5. Validate data through the repo workflow.

## Formula Runner

The formula runner supports basic arithmetic over numeric input keys:

```txt
+ - * / ( )
```

Good:

```txt
(advanceAmount * factorRate) / 90
```

Unsupported without runner code changes:

```txt
Math.max(totalPayroll - cashAvailable, 0)
```

Avoid conditionals, date math, caps, scoring, API calls, or text classification in formula runners until the runner supports them.

## Data Quality Notes

The validator checks:

- Required tool fields
- Required collection fields
- Duplicate slugs
- Input key uniqueness
- Supported input types
- Formula output references
- Missing collection tool slugs
- Optional tag taxonomy warnings
- Placeholder CTA warnings

Placeholder URLs should be replaced before using tools or collections as partner-ready assets.
