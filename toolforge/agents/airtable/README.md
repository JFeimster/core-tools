# Airtable Operating Guide

Use this pack for Airtable bases that need a structured but lightweight database-style workflow.

## Purpose

Airtable is best for workflows that need linked records, simple views, and operational clarity without custom app code.

## Best Use Cases

- Affiliate pipeline bases
- Lightweight CRM bases
- Document and intake tracking
- Small ops databases

## Target Users

- Affiliates
- Funding brokers
- Operators
- Consultants

## Repo Safety Rules

- Keep the schema small and understandable.
- Use the base to support one workflow at a time.
- Avoid invented relationships that are hard to maintain.
- Keep the output tied to a concrete artifact or data model.
