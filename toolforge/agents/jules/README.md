# Jules Operating Guide

Use this folder when working in Jules-style agent workflows against Core Tools.

## Purpose

Jules is a good fit for bounded repo tasks that benefit from clear steps, explicit outputs, and safe stop conditions.

## Use Cases

- Repo cleanup batches
- Static site build checks
- Documentation updates
- Batch validation before commit
- Small, schema-safe content changes

## When To Use It

Use the Jules workflow when the task needs a repeatable plan, guardrails, and a clear output package before review.

## How It Fits Core Tools

- Reinforces the repo's static-first build model
- Fits JSON-based tool and collection updates
- Supports validation-first editing
- Helps future batches stay disciplined and reviewable
