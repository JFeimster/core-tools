# Zapier Operating Guide

Use this pack for Zapier workflows that connect forms, CRMs, reminders, and lightweight follow-up tasks.

## Purpose

Zapier is best for simple event-driven automation that should stay readable, fast to set up, and easy to hand off.

## Best Use Cases

- Lead capture to CRM workflows
- Document reminder zaps
- Lightweight notification automations
- Simple partner handoff flows

## Target Users

- Funding brokers
- Affiliates
- Operators
- Small teams with simple workflow needs

## Repo Safety Rules

- Keep the spec focused on one trigger path.
- Do not add unsupported runtime assumptions.
- Keep the output tied to a concrete artifact or workflow.
- Prefer collection routes and repo docs for CTAs when possible.
