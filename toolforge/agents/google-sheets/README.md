# Google Sheets Operating Guide

Use this pack for spreadsheet-based tracking, intake, and lightweight automation support inside Core Tools workflows.

## Purpose

Google Sheets is best for simple operational tracking that needs to stay visible, editable, and easy to share.

## Best Use Cases

- Funding trackers
- Intake logs
- Pipeline dashboards
- Simple status sheets

## Target Users

- Funding brokers
- Operators
- Consultants
- Teams using spreadsheets as the source of truth

## Repo Safety Rules

- Keep the sheet structure simple and reviewable.
- Do not create hidden dependencies.
- Tie the sheet to one clear workflow or decision.
- Prefer practical columns over clever formulas.
