# Discord Operating Guide

Use this pack for Discord workflows that need community onboarding, affiliate ops, and lightweight support coordination.

## Purpose

Discord is best for community onboarding and partner ops that need a clear first step and visible channel structure.

## Best Use Cases

- Community onboarding
- Affiliate community ops
- Welcome flows
- Channel mapping

## Target Users

- Community managers
- Affiliate operators
- Founders
- Support teams

## Repo Safety Rules

- Keep the channel map simple and visible.
- Do not overcomplicate the moderation flow.
- Include a clear first action for new members.
- Keep community rules easy to follow.
