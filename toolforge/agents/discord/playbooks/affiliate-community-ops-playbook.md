# Discord Affiliate Community Ops Playbook

## When To Use

Use this when an affiliate community needs a support path, content flow, or partner onboarding structure.

## Required Inputs

- Audience
- Community goal
- Channel list
- Onboarding flow
- Moderation rules

## Optional Inputs

- Partner rules
- Event cadence
- Resource links
- Escalation path

## Workflow Steps

1. Define the community goal and audience.
2. Map the support and onboarding channels.
3. Add the moderation and escalation rules.
4. Write the first action for new affiliates.
5. Validate the flow with a sample member.

## Data Fields

- Member name
- Partner type
- Channel
- Status
- First action
- Owner

## Automation Logic

- Keep partner content and support paths separate.
- Route new members to the correct first action.
- Escalate rule violations to a human.

## Outputs

- Affiliate community map
- Onboarding flow
- Moderation notes
- Support path

## Validation Checks

- Channel map is complete
- First action is obvious
- Rules are visible
- Sample member path works

## Failure / Stop Conditions

- Missing support channel
- No onboarding action
- Unclear moderation path
- Repeated rule violations

## Handoff Notes

- Keep the community path short and understandable.
- Preserve the route to human support when needed.
