# Discord Community Onboarding Playbook

## When To Use

Use this when new members need a clear welcome flow, first action, and channel map.

## Required Inputs

- Community goal
- Audience
- Welcome message
- First action
- Channel list

## Optional Inputs

- Roles
- Rules
- Event cadence
- Escalation path

## Workflow Steps

1. Define the community purpose.
2. Write the welcome message.
3. Map the first action and the primary channels.
4. Add the role or rule notes.
5. Validate the flow with a sample new member.

## Data Fields

- Member name
- Role
- Channel
- First action
- Status

## Automation Logic

- Route new members to the correct welcome path.
- Keep the first action obvious.
- Escalate moderation issues when needed.

## Outputs

- Welcome flow
- Channel map
- First-action note
- Escalation note

## Validation Checks

- Welcome copy is correct
- Channel list is current
- First action is visible
- Roles map correctly

## Failure / Stop Conditions

- Missing channel map
- Conflicting rules
- No clear first action
- Repeated moderation issue

## Handoff Notes

- Keep the onboarding flow short.
- Make the next action obvious in the welcome message.
