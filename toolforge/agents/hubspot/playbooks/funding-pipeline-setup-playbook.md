# HubSpot Funding Pipeline Setup Playbook

## When To Use

Use this when a funding team needs a clear pipeline structure for leads, applications, and handoff stages.

## Required Inputs

- Pipeline goal
- Stage list
- Ownership rules
- Source mapping
- Follow-up rules

## Optional Inputs

- Deal types
- Stage labels
- Notification rules
- Reporting notes

## Workflow Steps

1. Define the pipeline purpose.
2. Choose the minimum stage set.
3. Set the ownership and source rules.
4. Add follow-up and status fields.
5. Validate the pipeline with a sample deal.

## Data Fields

- Deal name
- Source
- Stage
- Owner
- Due date
- Next step

## Automation Logic

- Keep stages ordered and explicit.
- Assign a clear owner to each deal.
- Flag stale deals for follow-up.

## Outputs

- Funding pipeline
- Stage map
- Follow-up queue
- Stale deal view

## Validation Checks

- Stage list is complete
- Owner logic is clear
- Source mapping works
- Sample deal moves correctly

## Failure / Stop Conditions

- Too many stage variants
- Missing owner rules
- Broken stage order
- Unclear source mapping

## Handoff Notes

- Keep the pipeline readable for the next operator.
- Avoid stages that only exist for reporting vanity.
