# HubSpot Operating Guide

Use this pack for HubSpot workflows that need pipeline setup, deal-stage hygiene, and funding-friendly CRM structure.

## Purpose

HubSpot is best for structured CRM work that needs clean stages, predictable ownership, and easy follow-up.

## Best Use Cases

- Funding pipeline setup
- Deal stage cleanup
- CRM ownership rules
- Follow-up workflows

## Target Users

- Funding brokers
- Sales operators
- Consultants
- Teams managing deal flow

## Repo Safety Rules

- Keep the pipeline model simple and reviewable.
- Do not assume unsupported runtime behavior.
- Keep the spec tied to a concrete funnel or workflow.
- Prefer a human fallback when rules are ambiguous.
