# 26 - Notion and HubSpot Ops Knowledge Sync SOP

## Notion + HubSpot Ops Knowledge Sync SOP  
### Moonshine Capital HubSpot CRM Operations Source Document

---

## 1. Purpose

This SOP defines how Notion and HubSpot should work together for Moonshine Capital operations.

Use this document when a workflow touches:

- Notion databases
- Notion SOPs
- Content calendars
- Course databases
- Partner resources
- CRM notes
- Applicant/partner records
- Project planning
- Knowledge base content
- HubSpot updates based on Notion context

The goal is to keep Notion as the planning/knowledge workspace and HubSpot as the CRM source of truth.

Notion is the war room.

HubSpot is the relationship ledger.

Do not make either one pretend to be both.

---

## 2. Source-of-Truth Rule

| Data Type | Source of Truth |
|---|---|
| Applicant contact info | HubSpot |
| Applicant lifecycle/status | HubSpot |
| Deals/pipeline/tasks | HubSpot |
| Partner/broker contact record | HubSpot |
| SOPs/source docs | Project sources / Notion |
| Content calendar | Notion |
| Course planning | Notion |
| Partner resources library | Notion/Wix depending public use |
| Project roadmap | Notion/GitHub depending build work |
| CRM execution history | HubSpot notes/tasks |

---

## 3. When to Use Notion

Use Notion for:

- SOP drafts
- Training materials
- Course outlines
- Content calendars
- Prompt libraries
- Partner resource databases
- Project planning
- Workflow architecture
- Internal knowledge bases
- Strategy docs

Do not use Notion as the main applicant CRM.

---

## 4. When to Use HubSpot

Use HubSpot for:

- Contacts
- Companies
- Deals
- Notes
- Tasks
- Applicant lifecycle
- Partner applicant status
- Follow-up accountability
- Relationship ownership
- Pipeline reporting

Do not bury applicant follow-up only in Notion.

---

## 5. Sync Workflow

```markdown
1. Identify whether the content is CRM data, knowledge, content, or project work.
2. Determine source of truth.
3. Search HubSpot if person/deal/company is involved.
4. Search Notion/source docs if SOP/resource/project context is involved.
5. Summarize relevant Notion context into HubSpot only if CRM-useful.
6. Link/reference Notion pages only when appropriate.
7. Do not duplicate whole Notion pages into HubSpot notes.
```

---

## 6. Notion → HubSpot Use Cases

| Notion Context | HubSpot Action |
|---|---|
| Partner resource page | Note resource sent / create task |
| Course completion info | Note/training status if relevant |
| Content calendar lead magnet | Note source if contact came from it |
| SOP update | No direct HubSpot update unless workflow changes |
| Partner profile database | Update HubSpot partner note/task |
| Project roadmap item affecting partner | Create HubSpot task/note only if partner-facing |

---

## 7. HubSpot → Notion Use Cases

| HubSpot Context | Notion Action |
|---|---|
| Repeated CRM workflow | Create/update SOP |
| New prompt pattern | Add to prompt library |
| Partner resource request repeats | Add resource idea to Notion |
| Course/training need emerges | Add curriculum/content idea |
| Automation need repeats | Add to workflow backlog |
| Reporting pattern repeats | Add reporting template |

Do not export sensitive applicant data into Notion unless the workspace is appropriate and secure.

---

## 8. HubSpot Note from Notion Context

```markdown
## Notion Context Reference Note

Related Notion resource: [Page/database name or link if appropriate]  
CRM relevance: [Why this matters to this contact/deal/partner]  
Summary:
[Short operational summary.]

Next action:
[Task/email/update needed.]
```

---

## 9. Notion Page Update from CRM Pattern

When a CRM workflow repeats, recommend creating/updating Notion/source docs.

Example:

```markdown
This follow-up pattern has repeated across multiple applicants. Recommend adding it to the HubSpot Task Templates or creating a Notion SOP update.
```

---

## 10. What Not To Do

Do not:

- Store active applicant pipeline only in Notion
- Duplicate HubSpot records into Notion unnecessarily
- Copy sensitive applicant docs into Notion without need/security
- Treat Notion database status as HubSpot deal status
- Use Notion as follow-up task system for active CRM work
- Lose CRM source links when summarizing from Notion
- Let SOP updates remain only in chat

---

## 11. Operational Standard

Use Notion for reusable knowledge and planning.

Use HubSpot for living CRM execution.

When something becomes repeatable, turn it into a source doc or Notion SOP.

When something requires follow-up, put it in HubSpot.
