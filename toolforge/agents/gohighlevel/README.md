# GoHighLevel Operating Guide

Use this pack for GoHighLevel workflows that need SMS follow-up, agency funnel support, and light automation around lead nurture.

## Purpose

GoHighLevel is best for campaign-style follow-up and funnel operations that need a practical handoff path.

## Best Use Cases

- Agency funnel workflows
- SMS follow-up campaigns
- Lead nurture sequences
- Simple partner follow-up flows

## Target Users

- Agencies
- Affiliate operators
- Funding brokers
- Teams running nurture campaigns

## Repo Safety Rules

- Keep the campaign spec bounded and reviewable.
- Do not assume runtime APIs or custom code.
- Preserve stop rules and opt-out handling.
- Tie the workflow to a concrete offer or funnel.
