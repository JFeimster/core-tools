# VS Code Operating Guide

Use this folder for local editor-driven work in Core Tools.

## Purpose

These files help a developer or agent work directly in the repo with an editor-first workflow while preserving the same validation and static-export constraints as the rest of ToolForge.

## Use Cases

- Local repository open and edit sessions
- Debugging static export issues
- Small code or doc updates
- Checking routes, data, and build state from the editor

## When To Use It

Use these guides when the work is being done from VS Code or a VS Code-like local editor environment.

## How It Fits Core Tools

- Keeps local edits disciplined
- Reinforces validation before commit
- Helps diagnose export or route issues quickly
- Works with the repo's JSON-driven architecture
