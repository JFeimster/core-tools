# Project Knowledge Sync

## Purpose

Use this playbook to keep project knowledge aligned with the current repo state.

## Steps

1. Read the current repo summary docs.
2. Identify new routes, docs, data files, or workflows.
3. Update the project knowledge source of truth.
4. Recheck for stale references.
5. Record any recommended next files or next actions.

## Guardrails

- Do not invent repo state
- Keep the summary compact
- Do not replace repo docs with the sync notes

## Inputs

- Current docs
- Recent commits
- Validation state

## Outputs

- Updated project knowledge
- Next-file guidance
- Noted gaps or follow-ups

## Stop Conditions

- Unclear repo state
- Missing source of truth
- Conflicting doc references
