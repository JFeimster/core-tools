# Notion Operating Guide

Use this folder for project knowledge and documentation sync workflows.

## Purpose

These files help future agents move repo knowledge into a structured project memory or research workspace without losing the shape of the actual repo.

## Use Cases

- Project knowledge capture
- Research-to-doc handoff
- Meeting prep and follow-up
- Structured summaries of repo changes

## When To Use It

Use this folder when the task is about recording or reusing project context rather than editing app behavior.

## How It Fits Core Tools

- Supports the project-data-snapshot pattern
- Keeps repo knowledge portable across threads
- Helps future batches start faster with less context loss
