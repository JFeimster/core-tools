# Slack Operating Guide

Use this pack for Slack workflows that need alerts, operator handoffs, and lightweight team coordination.

## Purpose

Slack is best for operational alerts and quick team coordination that supports a real workflow outcome.

## Best Use Cases

- Operator alerts
- Status notifications
- Human handoff messages
- Simple team coordination

## Target Users

- Operators
- Funding teams
- Support teams
- Automation builders

## Repo Safety Rules

- Keep alerts tied to a concrete event.
- Do not create noisy channels or redundant notifications.
- Include a clear stop or escalation rule.
- Keep the message copy short and actionable.
