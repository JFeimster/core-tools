# Skill Name

Lead Magnet Builder

## Purpose

Turn a useful idea into a lead magnet that can collect interest without feeling generic.

## Ideal User

Founders, consultants, affiliate marketers, and automation operators.

## Triggering Use Cases

- Checklist
- Template
- Scorecard
- Mini guide

## Required Inputs

- Audience
- Pain point
- Promise
- CTA
- Delivery format

## Process

1. Pick one audience and one pain point.
2. Define the useful artifact.
3. Write the delivery flow.
4. Add a clear CTA.
5. Check for realism and safety.

## Output Format

- Lead magnet concept
- Sections or pages
- CTA path
- Delivery notes

## Quality Bar

Useful enough that the user would keep it.

## Guardrails

- Avoid fake urgency
- Avoid hollow value props
- Keep the artifact specific

## Example Prompt

> Build a lead magnet concept that solves one clear problem and maps to a simple CTA.
