# Skill Name

Pipeline Follow-Up

## Purpose

Create a follow-up sequence that keeps active opportunities moving without spammy outreach.

## Ideal User

Sales operators, brokers, consultants, and partner teams managing deal flow.

## Triggering Use Cases

- Follow-up sequence
- Deal nudges
- Pipeline reactivation
- Next-step reminders

## Required Inputs

- Pipeline stage
- Opportunity type
- Follow-up goal
- Contact channel

## Optional Inputs

- Timing cadence
- Objection notes
- CTA

## Process

1. Define the next action the contact should take.
2. Choose the minimum number of follow-up touches.
3. Write concise messages by stage.
4. Add timing and ownership notes.
5. Keep the sequence respectful and direct.

## Output Format

- Follow-up sequence
- Message drafts
- Timing notes
- CTA path

## Quality Bar

Specific enough to use immediately without sounding robotic.

## Guardrails

- Do not spam
- Do not pressure the recipient
- Do not change the offer mid-sequence

## Compliance / Risk Notes

- Keep outreach aligned with consent and channel rules.

## Example Prompt

> Build a pipeline follow-up sequence for this opportunity stage with a clear next step and respectful cadence.
