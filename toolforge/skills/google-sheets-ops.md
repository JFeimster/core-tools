# Skill Name

Google Sheets Ops

## Purpose

Turn a spreadsheet workflow into a practical operations tool or tracking sheet.

## Ideal User

Operators, brokers, and consultants who run tracking in Google Sheets.

## Triggering Use Cases

- Tracking sheet
- Intake log
- Pipeline report
- Simple ops dashboard

## Required Inputs

- Sheet purpose
- Key fields
- Users
- Decision need

## Optional Inputs

- Formula notes
- Sharing rules
- Update cadence

## Process

1. Define the sheet's job.
2. Pick the minimum useful columns.
3. Organize the tabs or views.
4. Add notes for formulas or checks.
5. Keep the sheet usable without heavy training.

## Output Format

- Sheet structure
- Column list
- Tab list
- Formula notes

## Quality Bar

Simple, maintainable, and easy to extend.

## Guardrails

- Do not overbuild the sheet
- Do not mix unrelated workflows
- Keep formulas transparent

## Compliance / Risk Notes

- If the sheet tracks private or financial data, note who should have access.

## Example Prompt

> Create a Google Sheets ops structure for this workflow with a clean column set and simple checks.
