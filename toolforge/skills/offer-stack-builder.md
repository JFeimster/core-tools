# Skill Name

Offer Stack Builder

## Purpose

Structure an offer stack so the promise, proof, and next step are easy to understand.

## Ideal User

Founders, consultants, affiliates, and operators packaging an offer or service.

## Triggering Use Cases

- Offer page outline
- Value stack planning
- Upsell framing
- Productized service brief

## Required Inputs

- Core offer
- Audience
- Main outcome
- CTA

## Optional Inputs

- Bonuses
- Proof points
- Pricing notes

## Process

1. Define the core offer in one sentence.
2. List the strongest supporting pieces.
3. Sequence the value stack from strongest to lightest.
4. Call out proof and risk-reduction elements.
5. Keep the CTA simple and direct.

## Output Format

- Offer stack outline
- Proof list
- CTA plan
- Risk notes

## Quality Bar

Tight enough to fit into a landing page or sales brief without extra interpretation.

## Guardrails

- Do not inflate claims
- Do not pad the stack with filler
- Keep the offer coherent

## Compliance / Risk Notes

- If the offer implies regulated outcomes, add a review note and soften claims.

## Example Prompt

> Build an offer stack that makes this service easier to understand and buy.
