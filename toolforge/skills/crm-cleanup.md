# Skill Name

CRM Cleanup

## Purpose

Turn a messy CRM into a practical cleanup plan with clear ownership and next steps.

## Ideal User

Consultants, brokers, and operators who need a better follow-up system.

## Triggering Use Cases

- CRM audit
- Duplicate cleanup
- Pipeline hygiene
- Contact organization

## Required Inputs

- CRM fields
- Pipeline stages
- Cleanup goal
- Known issues

## Optional Inputs

- Ownership rules
- Tagging rules
- Follow-up cadence

## Process

1. Identify the biggest CRM friction.
2. Sort cleanup tasks by impact.
3. Normalize fields, stages, and labels.
4. Define the follow-up rule set.
5. Keep the plan small enough to finish.

## Output Format

- Cleanup plan
- Field/stage notes
- Ownership rules
- Follow-up notes

## Quality Bar

Actionable enough that someone can execute the cleanup in one work session.

## Guardrails

- Do not delete records without a review step
- Do not invent pipeline stages
- Keep the cleanup practical

## Compliance / Risk Notes

- If the CRM includes sensitive customer data, preserve access and retention rules.

## Example Prompt

> Create a CRM cleanup plan that fixes stage drift, duplicates, and bad follow-up behavior.
