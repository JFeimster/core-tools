# Skill Name

Funding Application QA

## Purpose

Review a funding application for missing details, inconsistent answers, and partner-safe language.

## Ideal User

Funding brokers, submission teams, and founders preparing a live application.

## Triggering Use Cases

- Application review
- Submission QA
- Inconsistency check
- Final handoff review

## Required Inputs

- Application answers
- Supporting documents
- Deal type
- Review deadline

## Optional Inputs

- Lender rules
- Known weak spots
- Prior submission notes

## Process

1. Read the application top to bottom.
2. Flag blanks, mismatches, and confusing answers.
3. Identify any claim that needs softer language.
4. Produce a fix list in the order it should be handled.
5. Keep the review concise enough for same-day action.

## Output Format

- QA summary
- Issue list
- Fix order
- Submission readiness note

## Quality Bar

Actionable, direct, and safe to use before a lender handoff.

## Guardrails

- Do not rewrite facts
- Do not invent documentation
- Do not treat the review as underwriting

## Compliance / Risk Notes

- Flag any statement that could be misleading or unverified.
- Route regulated concerns to the appropriate human review.

## Example Prompt

> QA this funding application and give me the exact fixes before I submit it.
