# ToolForge Skills Library

ToolForge skills are reusable work patterns for future agents and builders.

## Purpose

This library captures proven workflows for repo cleanup, static site work, tool spec writing, validation, deployment QA, knowledge sync, and related tasks.

## Use Cases

- Turning repeated repo work into reusable instructions
- Reusing a known process across different agent platforms
- Standardizing output quality for technical and content tasks
- Helping future batches start from a reliable baseline

## When To Use It

Use the skills library when a task is likely to repeat across branches, platforms, or projects.

## How It Fits Core Tools

- Supports the static-export, JSON-driven app model
- Reinforces validation-first changes
- Helps keep future utility expansion consistent
- Reduces prompt drift and one-off instruction noise
