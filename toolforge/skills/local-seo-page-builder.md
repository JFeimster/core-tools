# Skill Name

Local SEO Page Builder

## Purpose

Turn a local-service offer into a search-friendly page brief that can drive leads.

## Ideal User

Consultants, agencies, and local businesses building service pages or location pages.

## Triggering Use Cases

- Local service page
- Location page
- SEO brief
- Lead capture page

## Required Inputs

- Target service
- Location
- Audience
- Primary CTA

## Optional Inputs

- Proof points
- Competitors
- Service area notes

## Process

1. Define the service and city or region.
2. Pick one primary search intent.
3. Outline the sections that support trust and relevance.
4. Add a lead-capture CTA and proof cues.
5. Keep the scope narrow enough to ship quickly.

## Output Format

- Page brief
- Section outline
- CTA path
- SEO notes

## Quality Bar

Readable, specific, and useful for a page builder or copywriter.

## Guardrails

- Do not stuff keywords
- Do not overclaim local authority
- Keep the page focused on one service

## Compliance / Risk Notes

- If testimonials or rankings are referenced, make sure they are accurate and current.

## Example Prompt

> Build a local SEO page brief for this service and city with one lead-capture CTA.
