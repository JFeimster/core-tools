# Skill Name

Lead Magnet Builder for Operators

## Purpose

Turn a single operator problem into a lead magnet that earns attention and supports a clear CTA.

## Ideal User

Founders, consultants, affiliate operators, and brokers building list-growth assets.

## Triggering Use Cases

- Checklist
- Template
- Scorecard
- Mini guide

## Required Inputs

- Audience
- Pain point
- Promise
- CTA

## Optional Inputs

- Delivery format
- Follow-up sequence
- Proof points

## Process

1. Choose one audience and one problem.
2. Decide the helpful artifact.
3. Write the delivery flow and CTA.
4. Add practical value, not filler.
5. Keep the result simple enough to ship quickly.

## Output Format

- Lead magnet concept
- Section or page outline
- Delivery notes
- CTA path

## Quality Bar

Useful enough that the user would keep it and share it.

## Guardrails

- Avoid fake urgency
- Avoid empty promises
- Keep the scope narrow

## Compliance / Risk Notes

- If the magnet touches regulated claims, soften the language and add review notes.

## Example Prompt

> Build a lead magnet for operators that solves one real problem and points to one clear CTA.
