# Skill Name

Notion Ops

## Purpose

Use Notion as a structured workspace for plans, research, and project memory.

## Ideal User

Consultants, founders, and AI automation operators using Notion as the coordination layer.

## Triggering Use Cases

- Project notes
- Research synthesis
- Planning docs
- Status tracking

## Required Inputs

- Notion pages or database targets
- Sync intent
- Source files or notes

## Process

1. Identify the Notion target.
2. Map the source material.
3. Summarize or structure the content.
4. Keep the output easy to reuse.
5. Record follow-up items.

## Output Format

- Summary
- Action list
- Status update
- Open questions

## Quality Bar

The Notion artifact should be easy to scan and easy to update later.

## Guardrails

- Keep the structure simple
- Avoid duplicating long raw notes
- Keep the project memory current

## Example Prompt

> Turn this repo work into a clean Notion-ready summary with decisions, next steps, and open questions.

## Compatible Platforms

- Notion
- Codex
- Jules
- ChatGPT-style agents

## Related Core Tools Directory Opportunities

- Project knowledge packs
- Meeting prep notes
- Research synthesis
