# Skill Name

Business Credit Workflow

## Purpose

Structure a business-credit workflow into steps, tools, and content that can be shipped in Core Tools.

## Ideal User

Funding brokers, consultants, and founders building credit-readiness assets.

## Triggering Use Cases

- Business credit setup
- Tradeline readiness
- Credit building content
- Credit workflow planning

## Required Inputs

- Current credit stage
- Desired outcome
- Constraints
- Tool or content target

## Process

1. Define the credit goal.
2. Map the current stage.
3. Identify the needed steps.
4. Turn the workflow into a tool or playbook.
5. Check for compliance-safe language.

## Output Format

- Workflow outline
- Tool or playbook idea
- Step list
- CTA notes

## Quality Bar

Clear sequencing and no promise-heavy language.

## Guardrails

- Avoid approval language
- Avoid credit-score guarantees
- Keep the workflow practical

## Example Prompt

> Turn this business-credit process into a clean workflow I can ship as a Core Tools asset.

- Codex
- Jules
- Notion
- VS Code
