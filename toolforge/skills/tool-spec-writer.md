# Skill Name

Tool Spec Writer

## Purpose

Write a clean tool specification that can become JSON, a page, and a reusable product asset.

## Ideal User

Indie builders, founders, and automation operators turning ideas into directory tools.

## Triggering Use Cases

- Define a new tool
- Rewrite a rough idea into a clear spec
- Prepare a tool for validation and build
- Align a spec with the repo schema

## Required Inputs

- Tool idea
- Audience
- Artifact
- Inputs
- CTA

## Process

1. Clarify the user problem.
2. Define the output artifact.
3. Specify inputs and logic.
4. Choose tags and CTA.
5. Check schema fit.

## Output Format

- Tool summary
- Inputs
- Logic summary
- CTA
- Tag set

## Quality Bar

Specific enough to implement without guesswork.

## Guardrails

- No placeholder CTAs
- No unsupported schema fields
- No vague tool naming

## Example Prompt

> Write a schema-safe tool spec for this idea and make sure it can become a valid directory entry.

## Compatible Platforms

- Codex
- Jules
- VS Code
- Notion
- ChatGPT-style agents

## Related Core Tools Directory Opportunities

- New tool entries
- Collection entries
- Tool builder workflow
