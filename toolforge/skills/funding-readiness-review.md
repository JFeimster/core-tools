# Skill Name

Funding Readiness Review

## Purpose

Review a borrower or business profile and identify the gaps that matter before a lender handoff.

## Ideal User

Funding brokers, founders, and operators who need a quick readiness pass before submitting a file.

## Triggering Use Cases

- Pre-lender intake review
- Missing-document check
- Deal readiness summary
- Risk flag screening

## Required Inputs

- Borrower profile
- Funding goal
- Deal type
- Risk flags

## Optional Inputs

- Current documents
- Target lender type
- Submission deadline

## Process

1. Read the borrower profile and funding goal.
2. Identify missing facts, documents, and risk flags.
3. Decide whether the file is ready, close, or not ready.
4. Write the next-step checklist in plain language.
5. Keep the output safe for partner-facing use.

## Output Format

- Readiness summary
- Missing items list
- Risk notes
- Next-step checklist

## Quality Bar

Specific, practical, and short enough to use in a live intake conversation.

## Guardrails

- Do not promise approval
- Do not invent lender requirements
- Do not hide material risk

## Compliance / Risk Notes

- Keep the language advisory rather than definitive.
- Treat all readiness judgments as workflow guidance, not underwriting.

## Example Prompt

> Review this borrower profile and tell me what needs to be fixed before I send it to a lender.
