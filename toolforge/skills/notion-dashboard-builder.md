# Skill Name

Notion Dashboard Builder

## Purpose

Turn a workflow into a clean Notion dashboard brief with the right blocks and sections.

## Ideal User

Operators, founders, and consultants who run their process through Notion.

## Triggering Use Cases

- Dashboard brief
- Workflow hub
- SOP index
- Project tracker

## Required Inputs

- Workflow goal
- Users
- Key sections
- Required views

## Optional Inputs

- Templates
- Database relationships
- Navigation notes

## Process

1. Identify the main job the dashboard should do.
2. Group the content into clear sections.
3. Define the views and action buttons.
4. Add the minimum template set.
5. Keep the layout simple and reusable.

## Output Format

- Dashboard brief
- Section list
- View list
- Template notes

## Quality Bar

Easy to build and easy to maintain.

## Guardrails

- Do not overcomplicate the database structure
- Do not create unused views
- Keep the dashboard focused

## Compliance / Risk Notes

- If the dashboard stores sensitive information, note access and sharing boundaries.

## Example Prompt

> Build a Notion dashboard brief for this workflow with sections, views, and templates.
