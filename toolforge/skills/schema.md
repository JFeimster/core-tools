# Skill Schema

Use this schema for every ToolForge skill file.

## Required Sections

- Skill Name
- Purpose
- Ideal User
- Triggering Use Cases
- Required Inputs
- Process
- Output Format
- Quality Bar
- Guardrails
- Example Prompt
- Compatible Platforms
- Related Core Tools Directory Opportunities

## Writing Rules

- Keep the skill specific and reusable.
- State the expected output clearly.
- Include guardrails that match Core Tools constraints.
- Keep the process short and sequential.
- Avoid vague language like "improve things" or "make it better."

## Shared Quality Standard

A good skill file should be copy/paste usable without extra interpretation.
