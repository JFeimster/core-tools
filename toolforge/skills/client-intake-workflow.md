# Skill Name

Client Intake Workflow

## Purpose

Create a client intake flow that collects the right details without adding friction.

## Ideal User

Consultants, agencies, brokers, and service businesses with repeat intake steps.

## Triggering Use Cases

- New client onboarding
- Intake form planning
- Discovery call prep
- Handoff checklist

## Required Inputs

- Client type
- Offer or service
- Intake goal
- Required data

## Optional Inputs

- Follow-up path
- Internal owner
- Document checklist

## Process

1. Decide the minimum data needed.
2. Order the questions from easiest to hardest.
3. Separate qualification from onboarding.
4. Add the handoff and follow-up step.
5. Keep the flow short enough that people finish it.

## Output Format

- Intake workflow
- Question list
- Follow-up path
- Handoff notes

## Quality Bar

Short, usable, and easy to run manually or with a simple form.

## Guardrails

- Do not ask for unnecessary sensitive data
- Do not bury the first action
- Keep the process clear

## Compliance / Risk Notes

- If the workflow handles private or financial data, keep collection limited to what is needed.

## Example Prompt

> Build a client intake workflow for this service that gets to the useful facts fast.
