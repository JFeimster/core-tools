# Skill Name

Affiliate Onboarding

## Purpose

Create onboarding assets and sequences for affiliate or partner programs.

## Ideal User

Affiliate marketers, consultants, and operators managing partner funnels.

## Triggering Use Cases

- Affiliate welcome sequence
- Partner onboarding checklist
- Commission routing notes
- Enablement docs

## Required Inputs

- Partner type
- Offer
- CTA
- Compliance constraints

## Process

1. Clarify the partner role.
2. Define the first action.
3. Write the onboarding flow.
4. Add compliance notes.
5. Check for simple handoff paths.

## Output Format

- Onboarding sequence
- Asset checklist
- CTA guidance
- Compliance notes

## Quality Bar

Short, actionable, and safe for partner use.

## Guardrails

- Do not overpromise earnings
- Keep disclosures visible
- Avoid confusing handoff steps

## Example Prompt

> Build an affiliate onboarding sequence for this offer with clear steps, assets, and a single action path.

## Compatible Platforms

- Codex
- Notion
- VS Code
- ChatGPT-style agents
