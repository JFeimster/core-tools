# Skill Name

Bank Statement Prep

## Purpose

Turn messy bank statements into a clean prep checklist for underwriting or intake review.

## Ideal User

Funding brokers, bookkeepers, and founders collecting documents for a lender or partner.

## Triggering Use Cases

- Bank statement cleanup
- Deposit review
- NSF flag review
- Document collection prep

## Required Inputs

- Statement period
- Account type
- Document source
- Known issues

## Optional Inputs

- Average deposits
- Large transfers
- Missing statement months

## Process

1. Confirm the statement period and account type.
2. Identify missing months and unreadable pages.
3. Flag deposits, transfers, and unusual activity.
4. Produce a prep checklist for the next handoff.
5. Keep the result document-focused rather than judgmental.

## Output Format

- Prep checklist
- Missing-file list
- Flag list
- Submission notes

## Quality Bar

Clear enough that another person can assemble the file without extra interpretation.

## Guardrails

- Do not fabricate transactions
- Do not imply forensic review
- Do not give tax advice

## Compliance / Risk Notes

- Use this as document-prep guidance only.
- Escalate suspicious activity to the appropriate professional review path.

## Example Prompt

> Create a bank statement prep checklist from these statements and note anything that needs cleanup before submission.
