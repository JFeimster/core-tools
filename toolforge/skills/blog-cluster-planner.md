# Skill Name

Blog Cluster Planner

## Purpose

Plan a blog cluster around a topic, product, or directory category.

## Ideal User

Content operators, founders, and consultants building topical authority.

## Triggering Use Cases

- Cluster strategy
- Article grouping
- Internal linking plan
- Topic expansion roadmap

## Required Inputs

- Core topic
- Audience
- Offer
- Related tools or pages

## Process

1. Identify the pillar topic.
2. Map cluster subtopics.
3. Tie each topic to an offer or page.
4. Add internal links.
5. Check for overlap or duplication.

## Output Format

- Pillar page
- Cluster list
- Link map
- Publishing sequence

## Quality Bar

The cluster should be intentional, not a random content list.

## Guardrails

- Avoid duplicate angles
- Keep each article tied to a user need
- Do not overbuild cluster depth before the core page exists

## Example Prompt

> Plan a blog cluster for this topic and tie each article to a Core Tools asset or workflow.

## Compatible Platforms

- Codex
- Notion
- VS Code
- ChatGPT-style agents
