# Skill Name

SEO Brief Generator

## Purpose

Create a practical SEO brief for a page, tool, or collection.

## Ideal User

Founders, consultants, and content operators shipping search-focused assets.

## Triggering Use Cases

- SEO page brief
- Content target map
- Internal linking outline
- Query-focused page planning

## Required Inputs

- Topic
- Search intent
- Audience
- Primary page
- Related assets

## Process

1. Define the target search intent.
2. Map the page purpose.
3. List the needed sections.
4. Add internal links and CTA guidance.
5. Note any compliance or quality issues.

## Output Format

- Brief summary
- Heading plan
- Internal links
- CTA notes

## Quality Bar

Specific enough for a writer or builder to use immediately.

## Guardrails

- Avoid keyword stuffing
- Avoid unsupported claims
- Keep the brief tied to the actual offer

## Example Prompt

> Write an SEO brief for this page with intent, section outline, and internal link suggestions.

- Codex
- Notion
- VS Code
- ChatGPT-style agents
