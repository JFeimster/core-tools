# Skill Name

Content Repurposing

## Purpose

Turn one source asset into a practical set of repurposed pieces for different channels.

## Ideal User

Founders, consultants, and operators who need more output from one strong piece of content.

## Triggering Use Cases

- Blog-to-social repurpose
- Webinar-to-email reuse
- Post-to-landing-page adaptation
- Asset-to-sequence conversion

## Required Inputs

- Source content
- Target channel
- Audience
- Main message

## Optional Inputs

- Voice notes
- CTA
- Proof points

## Process

1. Identify the strongest source idea.
2. Extract the reusable message blocks.
3. Adapt the content for the target channel.
4. Keep the CTA consistent.
5. Drop anything that does not help the next asset ship.

## Output Format

- Repurposing map
- Channel-specific drafts
- CTA notes
- Reuse plan

## Quality Bar

Useful across channels without sounding copied and pasted.

## Guardrails

- Do not change the claim
- Do not drift from the audience
- Do not add filler for volume

## Compliance / Risk Notes

- Preserve disclosures, attribution, and source-specific restrictions.

## Example Prompt

> Repurpose this source content into a practical channel-by-channel plan for a founder audience.
