# Skill Name

Calculator Spec Builder

## Purpose

Turn a calculator idea into a clear spec with inputs, outputs, and safe logic boundaries.

## Ideal User

Founders, brokers, and operators building decision tools or lead-capture calculators.

## Triggering Use Cases

- Calculator concept
- Input/output planning
- Formula scope review
- Decision tool brief

## Required Inputs

- Audience
- Calculation goal
- Inputs
- Desired output

## Optional Inputs

- CTA
- Risk notes
- Formula constraints

## Process

1. Define the decision the calculator should support.
2. Choose the minimum inputs that matter.
3. Specify the output and the explanation text.
4. Keep the formula scope simple and testable.
5. Note any risk or compliance considerations.

## Output Format

- Calculator spec
- Input list
- Output list
- CTA notes

## Quality Bar

Specific enough for implementation without additional design guessing.

## Guardrails

- Do not require unsupported logic
- Do not make the calculator promise outcomes
- Keep formulas simple and auditable

## Compliance / Risk Notes

- If the tool touches lending, taxes, or regulated topics, add a review note before publishing.

## Example Prompt

> Build a calculator spec that helps a user make one clear decision and points to a useful CTA.
