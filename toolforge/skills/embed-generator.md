# Skill Name

Embed Generator

## Purpose

Create embed-ready content and layout guidance for tools or playbooks.

## Ideal User

Affiliate marketers, consultants, founders, and automation operators.

## Triggering Use Cases

- Build an iframe embed page
- Create a compact widget view
- Document embed behavior
- Prepare a shareable mini-app surface

## Required Inputs

- Tool or playbook spec
- Output requirements
- Embed constraints
- CTA destination

## Process

1. Inspect the source offer.
2. Define the minimal embed experience.
3. Keep layout compact and useful.
4. Preserve static-export compatibility.
5. Validate the embed output.

## Output Format

- Embed structure
- Copy guidance
- CTA notes
- Validation notes

## Quality Bar

The embed should be concise, useful, and easy to drop into a static site.

## Guardrails

- No runtime dependency creep
- No hidden state requirements
- No bloated UI

## Example Prompt

> Turn this tool into a compact embed-ready experience with a clear CTA and a minimal layout.

## Compatible Platforms

- Codex
- VS Code
- Vercel
- ChatGPT-style agents

## Related Core Tools Directory Opportunities

- Tool embed pages
- Shareable mini tools
- Partner widgets
