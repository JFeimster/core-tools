# Skill Name

Calculator Design

## Purpose

Design a calculator that is simple, useful, and implementable in the Core Tools schema.

## Ideal User

Founders, finance operators, and builders shipping practical decision tools.

## Triggering Use Cases

- Estimator
- Analyzer
- Checker
- Scorecard

## Required Inputs

- User problem
- Inputs
- Output artifact
- CTA

## Process

1. Define the calculation goal.
2. Choose only necessary inputs.
3. Describe the output clearly.
4. Avoid unsupported logic.
5. Match the schema fields.

## Output Format

- Calculator concept
- Inputs
- Output text
- CTA guidance

## Quality Bar

The calculator should be easy to use and easy to explain.

## Guardrails

- No hidden business logic
- No unsupported formula complexity
- No vague output labels

## Example Prompt

> Design a calculator for this use case with simple inputs, clear outputs, and schema-safe logic.

## Compatible Platforms

- Codex
- Jules
- VS Code
- ChatGPT-style agents

## Related Core Tools Directory Opportunities

- Tool pages
- Embed pages
- Funding and ecommerce tools
