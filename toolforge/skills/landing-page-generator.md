# Skill Name

Landing Page Generator

## Purpose

Create or improve landing-page copy and structure for a tool, playbook, or lead magnet.

## Ideal User

Founders, affiliate marketers, real estate pros, e-commerce sellers, and consultants.

## Triggering Use Cases

- Write a campaign landing page
- Convert a tool into a page outline
- Create a lead capture page
- Draft a partner-friendly offer page

## Required Inputs

- Offer summary
- Audience
- Primary CTA
- Proof points
- Constraints

## Process

1. Clarify the offer and audience.
2. Draft a page structure.
3. Write benefit-driven copy.
4. Add CTA and trust elements.
5. Check for clarity and compliance.

## Output Format

- Page outline
- Hero copy
- Section copy
- CTA copy

## Quality Bar

Clear, direct, conversion-focused, and specific to the audience.

## Guardrails

- Avoid vague marketing filler
- Avoid unsupported claims
- Keep CTA language aligned to the offer

## Example Prompt

> Generate a landing page for this offer with a strong hero, clear sections, and a single conversion CTA.

- ChatGPT-style agents
