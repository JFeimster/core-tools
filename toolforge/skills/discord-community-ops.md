# Skill Name

Discord Community Ops

## Purpose

Turn community management into a simple ops workflow with clear moderation and follow-up steps.

## Ideal User

Creators, founders, and operators running a Discord community or partner hub.

## Triggering Use Cases

- Community moderation
- Welcome flow
- Engagement cadence
- Partner support channel

## Required Inputs

- Community goal
- Audience
- Moderation rules
- Key channels

## Optional Inputs

- Welcome message
- Escalation rules
- Event cadence

## Process

1. Define the community goal.
2. Decide the first message and first action.
3. Map the moderation and escalation rules.
4. Add the engagement cadence.
5. Keep the workflow simple enough to run consistently.

## Output Format

- Community ops checklist
- Welcome flow
- Moderation notes
- Engagement cadence

## Quality Bar

Useful for the people running the server, not just the people joining it.

## Guardrails

- Do not overmoderate
- Do not bury the welcome action
- Keep the rules clear

## Compliance / Risk Notes

- If the community includes offers or disclosures, make the rules visible.

## Example Prompt

> Build a Discord community ops checklist with welcome, moderation, and follow-up steps.
