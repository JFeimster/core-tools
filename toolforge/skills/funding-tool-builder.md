# Skill Name

Funding Tool Builder

## Purpose

Turn funding-related ideas into practical tools, playbooks, or lead magnets.

## Ideal User

Funding brokers, consultants, founders, and lenders building acquisition or readiness flows.

## Triggering Use Cases

- Funding readiness review
- Bank statement prep
- Lender match brief
- Funding application QA

## Required Inputs

- Audience
- Funding goal
- Risk flags
- Inputs
- CTA path

## Process

1. Identify the funding use case.
2. Define the decision artifact.
3. Set the inputs and outputs.
4. Choose partner-safe language.
5. Validate the result against the repo schema.

## Output Format

- Tool spec
- Copy outline
- Risk notes
- CTA recommendation

## Quality Bar

Practical, specific, and safe for partner-facing use.

## Guardrails

- No approval promises
- No rate promises
- No claim inflation

## Example Prompt

> Build a funding tool spec that helps users prepare for a lender conversation without making approval claims.

## Compatible Platforms

- Codex
- Jules
- Notion
- VS Code

## Related Core Tools Directory Opportunities

- Funding readiness tools
- Collections for lender workflows
- Partner-facing playbooks
